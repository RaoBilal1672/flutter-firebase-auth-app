# Firebase Authentication App 🔐

A Flutter application integrated with Firebase Authentication that allows users to securely create accounts, log in, and log out using Email and Password authentication.



## Features

- User Registration (Sign Up)
- User Login
- User Logout
- Firebase Authentication Integration
- Secure Email & Password Authentication
- Responsive UI Design
- Error Handling and Validation
- Cloud-Based User Data Storage
- User account remains available after app reinstallation because authentication data is securely managed by Firebase.

## Technologies Used

* Flutter
* Dart
* Firebase Authentication
* Firebase Core

## How to Run

1. Clone the repository
2. Open the project in Android Studio
3. Run:

```bash
flutter pub get
```

4. Configure Firebase
5. Run the application

```bash
flutter run
```

## Application Flow

1. Create a new account using Email and Password
2. Login using registered credentials
3. Access the Home Screen
4. Logout securely
